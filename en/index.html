Inside Verbbe

There’s no third-party catalog. You play what you already own.

Library

Songs, albums, artists, genres, and playlists. Tags from the file: title, track, disc, year, BPM, composer.

Player

Mini player, full screen, queue, shuffle, repeat, and favorites. Lyrics if the file has USLT or the server indexed them.

Verbena

iPhones on the same network, a code or a stamp. Guests see the host’s catalog and can control playback; files aren’t copied.

Cover editor

If an album has no art, you draw it: layers, a photo from the library, a palette. It stays on the device or on your server.

Search

Over what’s in this source. It doesn’t query someone else’s catalog. Switch local to server, and what you find switches with it.

Support the artist

The player matches the tag name against a public list. If there’s a store, it opens it. Verbbe takes 0%.

Local streaming

One command. The library on the PC.

One command on your computer. It uses the music folder you already have, without copying it. Open the page, create your account, and paste the address on the iPhone. verbbe stop turns the server off; the songs stay where they were.

verbbe 
$ curl -fsSL https://verbbe.com/install.sh | bash
$ verbbe start --music ~/Music

Questions

Before you install

Do I need the server?

No. The core is local. The server is for the PC folder and for listening away from home.

Where is the /music folder?

It only exists inside Docker. On the Mac or PC it’s ~/Music (or your --music path). The panel can open it in Finder or Explorer.

What is the API key for?

For scripts or other apps. The iPhone signs in with email and password. If you don’t have an integration, you don’t need one.

Where does it store data?

Songs stay in your folder. The catalog (Postgres), artwork, and secrets go to ~/.verbbe for your Mac or PC user, not a fixed account. Backup: verbbe backup.

How do I uninstall it?

Use the Remove console: verbbe uninstall. It asks whether to delete the catalog. Music is not deleted. Pause only: verbbe stop. Keep data: --keep-data.

Does it always install for the same user?

No. It uses whoever runs the CLI: their ~/Music and their ~/.verbbe. If that Mac account is ismael, those are ismael’s paths; on Ana’s machine, Ana’s.

Does it play Spotify, Apple Music, or YouTube?

No. It doesn’t connect to those catalogs. You play files you have, here or on a server you run.

Does the iPhone install Tailscale?

No. Tailscale runs only on the computer. The phone only needs Verbbe, the URL (home or Away), and your user.

Is there Android?

Not yet. The app is iOS 17+. Google Play is on the way, no date.

What does it cost?

The app is free. There’s an optional tip through Apple; it doesn’t unlock features. You run the server.

Who sees my music?

Nobody on the developer’s side. Locally, this iPhone. On a server, that machine’s accounts. In a Verbena, whoever has the code on your network.
